3. 总分公式与及格线

VAS = 0.18·L1 + 0.28·L2 + 0.10·L3 + 0.18·L4 + 0.16·L5 + 0.10·L6

正式口径 official：
  未实现 / 未跑套件 / 无 GT 无法算 → 指标分 = 0
  禁止只对「已测层」重归一化后对外宣称 VAS

及格线：VAS < 60 不及格 | 60–74 及格 | 75–89 良好 | ≥90 优秀
副指标（不进分）：Cost、Tokens、WallTime、ToolCalls、pass^k

5. 机制与反虚高

  • A 自动 / B LLM grader（需 κ≥0.70 校准）/ C 专家。
  • 单样本成功 ≠ L5/L6 得分；缺扰动套件则 L5=0；缺打回闭环则 L6=0。
  • L1.VER=0 ⇒ L2/L4 结果类指标强制 0（级联）。
  • 跨 Agent：统一 AUT 产物接口后用同一套指标卡；主排序 VAS，并列看 pass^k→Cost。
