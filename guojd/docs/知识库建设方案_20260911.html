知识库建设方案：本地可发布、可引用、可审核

2026-09-11　|　权威源在 wangdaxi；XvirMind 只做发布快照与引用，不改源仓

护城河是垂直知识，不是前端。知识库必须本地、可哈希、可回滚、可被报告引用。Agent 只检索已发布的 pack，不能把模型记忆当成 ICTV 规则。

1. 权威源与职责

层位置职责
分类真相源wangdaxi/Projects/virus_taxonomy · data/kb/kb.jsonl + taxonomy.dbICTV 科/属界分规则、MSL40 名录。唯一可被定种引用的规则文本。
RNA 注释增量wangdaxi/rna_virus_annotation · intrafamily split + rva_annotate.py弱同源 RNA 病毒基因结构/结构域。不替代 W6 流程注释。
发布快照XvirMind/knowledge/releases/<pack_id>子集 + sha256 + manifest。分析页和报告只引用 pack，不直读正在编辑的源文件。
查询插件MCP :8766/:8767只读检索；计算默认 dry-run。

2. 发布流水线

harvest 源仓 kb.jsonl / RVA split
  → validate JSONL 与 family 白名单
  → subset（本 demo：Flaviviridae, Coronaviridae, Adenoviridae）
  → hash（源文件 + 产物）
  → publish knowledge/releases/<date-version>/manifest.json
  → latest 符号链接
  → 分析页 / 报告 citation.knowledge_release = 该路径

命令：python3 xvirmind/scripts/publish_knowledge_pack.py --version 20260911-demo

规则：发布失败则继续使用上一成功 pack；禁止静默落到「模型记得的科名」。

3. 引用合同

  • 每条定种/科级规则必须带 corpus=ictv、knowledge_release、locator（如 taxon.family=Flaviviridae）。
  • 缺 locator → 完整性规则 INCOMPLETE_EVIDENCE，报告写「未提供」，专家可打回。
  • W2 科与 RVA 科不一致 → FAMILY_CONFLICT，不能自动消解。
  • RVA 未确认实跑 → RVA_NOT_CONFIRMED，允许出报告但不得写成已注释完成。

4. Demo 怎么验

  1. 打开 http://127.0.0.1:3080/knowledge（本机 XvirMind Host，不依赖 cyclone 写权限）。
  2. 看到 pack 20260911-demo、成员表、W1–W4+W6 队列估计、RVA 实跑状态。
  3. 评估 demo 候选：Flaviviridae 完整；Coronaviridae vs Flaviviridae 冲突被打回。
  4. 交付预览含定种、RVA、kb.jsonl 引用。静态副本：knowledge/demo/delivery_report_preview.html。
