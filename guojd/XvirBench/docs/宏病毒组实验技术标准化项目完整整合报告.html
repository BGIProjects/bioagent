1. 项目目的与总体框架

1.1 项目目的

本项目面向宏病毒组/宏转录组跨宿主、跨样本类型标准化需求，核心目标是建立一套适用于不同宿主与样本类型的宏转录组标准化操作流程（SOP），提升病原体检测的一致性与可比性。项目需要解决的核心问题不是单次样本能否测出结果，而是不同宿主、不同样本类型、不同建库和 rRNA 去除策略下，如何形成可比较、可审计、可规模化、可推广的共识性方法。

项目处于 X 传染病监测与未知病原体检测的应用背景之下，但本项目成果不直接纳入国家重大专项任务书交付；优先路径为高水平方法学论文，再视成熟度推进团体标准或行业指南。现有宏转录组实验流程在组织、粪便、拭子、虫体等样本之间差异很大，核酸完整性、抑制物、宿主背景、rRNA 占比和低输入问题都会影响建库成功率和下游检出。因此，本项目采用“主流程 + 分支流程 + 统一指标框架”的方式推进，并以多团队协作（科研机构统筹设计与质控、试剂方与测序/探针方协同）落地可推广 SOP。

1.2 总体目标

项目总体目标包括五类交付：

1. 建立覆盖样本采集、保存、核酸提取、rRNA 去除、RNA 打断/逆转录、建库、测序和生信分析的标准化 SOP（一期以提取后关键环节为主，见第 4 章边界）。

2. 明确组织、粪便、拭子、虫体四类动物源性样本中哪些环节可通用，哪些环节必须分流；一期暂不包括环境样本。

3. 建立跨宿主 rRNA 去除与建库策略评价体系，优先比较酶法与探针法（含 LNA、RNase H 等）的去除效率及适用边界，并联动建库效果评价。

4. 建立 XvirBench 统一指标框架，使不同批次数据进入同一 metric_id、manifest、registry 和 harmonized 表体系。

5. 成果路径：优先发表高水平方法学论文；后续联合推进团体标准/行业指南（含正在制定的未知病原体检测团体标准），不以国家标准或重大专项任务为近期硬交付。

1.4 标准化路线

项目采用“实验标准化 + 指标标准化”双线并行。实验侧通过分阶段模块化测试收敛流程；一期实验变量优先控制为“高质量 RNA / 降解 RNA”（或优质核酸 / 劣质核酸），避免同时叠加提取品牌、保存液类型等多重变量。数据侧通过 XvirBench 将 W1-W7 输出统一到可比较指标空间。最终形成一套组织和高质量拭子样本可优先采用的主流程，同时保留粪便、虫体/超低输入、高降解/高背景样本的分支流程。时间上力争第一年内（秋季前）完成核心方法学论文撰写。

2. 标准化规范体系

2.1 样本与元数据规范

所有样本进入实验前必须具备统一登记信息，包括物种、样本类型、采样时间、地点、保存方式、样本重量或体积、冻融次数、前处理方式、提取批次、建库批次、测序批次和分析批次，并登记 RNA 质量分级（高质量 / 降解或 RIN/DV200）。样本编号建议采用全局唯一 ID，同时保留本地样本 ID 和合作方原始编号，避免后续多批次合并时出现重复或错配。

一期样本策略按专家共识执行：优先统一采集新鲜样本并以液氮/干冰保存运输，保留冷链记录；组织、拭子、粪便、虫体四类尽量重新采样，避免混用历史存样引入不可控变量；不纳入环境样本。低载量样本（血清、脑脊液等）与高降解样本作为专项评估子集，降解可人为模拟以便对照。样本进入比较实验时采用盲法编号和分层随机，尤其在 rRNA 去除比较中应尽量使用同一样本等量分装的严格配对设计。

2.2 实验流程规范

推荐主流程为：

RNA 提取 -> DNase 处理 -> rRNA 去除 -> RNA 打断 -> 逆转录 -> 二链合成 -> 文库构建 -> PE150 测序 -> 统一生信分析。

该主流程优先适用于组织样本和质量较好的拭子样本。分支流程包括：

分支适用场景技术要点
粪便分支高抑制、高复杂背景强化去抑制提取，必要时降低去背景强度以减少目标损失
虫体/超低输入分支单虫、混虫、蜱虫等低输入复杂基质优先保证回收率，减少分装损耗，必要时采用轻打断或不打断
高降解/高背景分支RNA 完整度差或宿主背景异常高避免过度碎片化，保留可建库模板；比较“是否打断”对低质量样本建库的影响

一期提取环节统一采用诺唯赞现有试剂盒作为基准流程，不在一期展开多品牌提取对比；主流程与分支流程差异主要体现在 rRNA 去除强度、打断策略和低输入回收策略上。

2.3 rRNA 去除与探针策略

rRNA 去除是本项目一期核心比较变量。优先比较酶法与探针法（含 LNA、RNase H 等路线）的去除效率、有效数据提升和对病毒检出的影响；不去除条件作为对照，商业高端试剂盒仅作小规模 benchmark。长期方案不追求“单一探针覆盖全部物种”，而采用类群通用探针池加补丁探针池的策略：脊椎动物通用探针池、节肢动物特异探针池等，并结合 LNA 修饰提高结合稳定性和特异性（探针研发与测序平台侧由华大协同）。

评价标准不应只看 rRNA 残留率，还要联合测序有效数据、建库成功率、病毒检出、微生物谱稳定性、成本和操作复杂度。对于哺乳动物组织可设更严格 rRNA 残留标准；节肢动物因参考序列不足、背景差异大，应更重视相对提升幅度和可推广性。

4. 测试方案与验证设计

4.1 一期 240 份真实样本设计

一期计划纳入 240 份真实样本（对应约 750–850 / 目标 500–1000 个文库），覆盖组织、粪便、拭子和虫体四类关键技术场景；均为动物源性样本，不含环境样本。样本优先新鲜采集，四类尽量重新采样。

样本类型样本数主要研究目的
组织70建立主流程，比较 rRNA 去除与打断策略（高质量 vs 降解分层）
粪便40在统一提取基准下优化高抑制/高背景的去 rRNA 与建库策略
拭子70优化低输入回收、打断策略与保存条件适配
虫体60优化单虫/混虫、低输入和复杂背景的去 rRNA/建库流程
合计240支撑主流程和分支流程收敛

另设专项评估子集：低载量样本（血清、脑脊液等）与人为模拟降解样本，用于检验流程在极端条件下的检出表现，不挤占上述四类主矩阵的核心比较功效。

时间目标：约 6 个月完成第一阶段验证，并支撑年内核心论文撰写。

4.3 模块化测试设计与一期排除项

一期核心变量控制： 明确实验主变量为“高质量 RNA”与“降解 RNA”（优质核酸 / 劣质核酸）两类，在统一提取基准上比较下游处理差异；避免同时叠加提取试剂品牌、保存液类型、复杂前处理等多重变量。

模块一期是否开展内容
模块 A：核酸提取比较否（留待二期）采集方式、保存方式、提取原理及同原理不同试剂盒变量过多，商业试剂盒难以精准控制单一变量；一期统一以诺唯赞现有试剂盒为基准
模块 B：rRNA 去除比较是（核心）不去除对照、酶法、探针法（LNA / RNase H 等）；商业高端试剂盒仅在第一阶段选 8–12 份代表性样本作 benchmark，不建议全量铺开
模块 C：打断与建库策略是（核心）用优质核酸验证逆转录前打断顺序的科学依据；比较是否打断对低质量/高降解样本建库效果的影响；保留轻打断或不打断分支候选
复杂前处理否（一期排除）暂不纳入靶向富集、病毒颗粒负极（VLP）、VSP 等

4.4 质控与对照

每批实验至少设置提取空白、建库空白、外源 RNA spike-in、Mock 阳性对照和技术重复；并记录 RNA 质量分级以便按高质量/降解分层分析。异常样本包括样本信息不完整、严重腐败污染、材料不足、建库失败、对照异常、同批重复偏差过大等，必须在进入统计分析前完成判定。

5.2 统计分析原则

rRNA 去除模块应优先采用同一样本等分后的配对分析；主流程和分支流程比较应按样本类型和宿主类别分层；方法优选不以单一 p 值为依据，而结合效应量、置信区间、稳定性、成本和可解释性。小样本阶段的统计结论仅作为筛选依据，不能替代第二、第三阶段验证。

8.3 最终建议

当前应将三组测试结果定位为“前期测试基础”，不是最终标准结论。项目正式推进时，应以 240 份真实样本、约 500–1000 文库作为一期标准化验证主体；二期再扩展提取比较、环境样本与复杂前处理。汇报时建议强调六点：第一，一期定位是可推广的宏转录组 SOP 与方法学论文，而非重大专项任务交付；第二，应用范围限定动物源性四类样本，不含环境样本；第三，方法学比较聚焦提取后的 rRNA 去除与建库，提取横向对比留二期并以诺唯赞试剂盒为基准；第四，实验主变量控制为高质量 vs 降解核酸，避免多重变量叠加；第五，rRNA 去除与打断策略需联合宿主 QC、病毒定量等证据判断，XvirBench 与 W1 QC 规范构成可比较证据链；第六，协作上华大负责测序/探针、诺唯赞负责提取与去 rRNA 试剂、科研机构统筹设计质控，并联动未知病原体检测团体标准。
